# 2026 Nebraska U.S. Senate general election: polling sources

Collected 2026-10-26 for the forecast's documented polling override.
Candidates: Pete Ricketts (R, incumbent) and Dan Osborn (I). There is no Democratic nominee. Minor candidates named on some full ballots: Mike Marvin (Legal Marijuana Now), Robin Richards (Nebraska Working People), Chuck Conboy (America First).
Every file below was retrieved on **2026-10-26**. The Wayback copy carries its capture date in its filename.
Margins below are Osborn minus Ricketts.
